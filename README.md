# RuesMother

**RuesMother（ルーマザー）** は、Unityで開発中の2Dアクションゲームです。

プレイヤーは主人公「ルー」を操作し、召喚したキャラクター「ゲーウェン」と共にステージを攻略していきます。

キャラクターアクションに加え、攻撃方法のカスタマイズや敵から得た能力を組み合わせることで、自分なりの戦い方を作れるゲームを目指して開発しています。

---

## 🎮 ゲーム概要

* ジャンル：2Dアクションゲーム
* 開発環境：Unity
* プレイ人数：1人
* 開発状況：開発中

### 特徴

* キャラクターを活かした2Dアクション
* 剣や飛び道具などを使った多彩な攻撃
* 攻撃や能力を組み合わせるカスタマイズ要素
* ステージごとの敵やギミック、ボスとの戦闘

---

## 🕹️ プレイ方法

現在、体験版を開発中です。

### Unityから起動する場合

1. このリポジトリをCloneまたはDownloadします
2. Unity Hubからプロジェクトを開きます
3. ゲーム開始用のSceneを開きます
4. Unity Editor上部の「Play」ボタンから実行します

※開発中のため、仕様や操作方法は変更される場合があります。
